Data Analysis has been done using Excel. Tables, Power Query, Data Modelling, Pivot tables, Power Pivot, Charts, Slicers, and Timeline slicers are used for data analysis and dashboard visualization.

Raw data sets contains three csv files:
1. customers.csv
2. orders.csv
3. products.csv

Raw data sets are first loaded into main analysis excel file using power query, transformed, cleaned and then loaded to 3 tables.

Data modelling is done via Power Pivot with star schema approach. Fact table is "orders" and "customers" and "products" tables are dimension tables.

Pivot tables are inserted from data model.

Descriptive data analysis has been done and following questions are answered:
1. Total orders.
2. Total sales
3. Average customer spending.
4. Average order delivery time.
5. Order quantity vs delivery time (Correlation).
6. Occasion wise revenue.
7. Product category wise revenue.
8. Revenue based on order hour.
9. Month wise revenue.
10. Top 10 cities with most number of orders.
11. Top 5 best selling products.
